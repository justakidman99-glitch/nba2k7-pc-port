Before you start

  1. Run the ISO in PCSX2. Create a fresh memory card for this project.
  2. Start the game, then save the untouched default roster to the card once, so you have something to go back to.
  3. Close PCSX2 and copy the memory card file somewhere safe (in PCSX2's memcards folder, usually Mcd001.ps2).
  4. Test on one team first (see the box to the right). Only then do the whole league.
  5. For each team: release the old players to free agency, sign LeBron to Philadelphia, create the new players, and assign them.
  6. Save the roster after every team. Back up the memory card file every few teams.

Test these first

I can't confirm these limits from the disc. Check them in game before you commit hours:

  • Create Player cap. The league needs about 500 new players. If 2K7 caps created players lower than that, enter the top 13 per team first (marked rows are two-way contracts and can be skipped).
  • Roster size. 2K7 probably allows 15 per team and may require a minimum of 12 or 13. Some teams below list 16–19, so drop the two-way and least-used players first.
  • Release limits. Check whether the game lets a team go below the minimum while you swap players. If not, create a team's new players first, then release the old ones.
Never edit the ISO itself for this. All changes live on the memory card, so a mistake costs you a roster save, not the game.

Ratings

The OVR column is a suggested overall on a 2K-style scale:

95–98MVP level
88–94All-NBA
83–87All-Star
77–82Good starter
70–76Rotation player
62–69End of bench, two-way

In Create Player you set individual attributes, and the game works out the overall. Raise the attributes that fit the position until you land near the target: ball handling, passing and speed for point guards; shooting and perimeter defense for wings; inside scoring, rebounding, blocks and strength for bigs.

The dashed line on each team marks its top 13. If you run out of Create Player slots, stop at the line.

These ratings are my own estimates, based on how each player performed through 2025–26 and on draft position for rookies. Adjust anyone you think is off.
